Week 2

Week 2 从特征与权重开始深入。首先给出特征矩阵 $X$（例如水果分类场景），需要找出特征对应的权重 $W$。通过矩阵乘法 $X \cdot W$，即得到如下经典判定公式：

$$y = \begin{cases} 0 & (b + w_1x_1 + w_2x_2 \leqslant 0) \\ 1 & (b + w_1x_1 + w_2x_2 > 0) \end{cases}$$

公式参数拆解：

  • $y$：输出变量（Output），只能取两个值：0（Non-Activated）或 1（Activated）。
  • $x_1, x_2$：输入特征值（Input Features），代表已知条件或特征（如商品的售价与评价得分）。
  • $w_1, w_2$：权重（Weights），对应特征的重要程度系数。绝对值越大影响越大，正值促进，负值抑制。
  • $b$：偏置（Bias），控制模型触发激活状态的门槛难度。

整体逻辑：

表达式 $b + w_1x_1 + w_2x_2$ 为加权综合得分：

  • 综合得分 $\leqslant 0$ 时：未达到门槛，输出 $y = 0$。
  • 综合得分 $> 0$ 时：触发门槛，输出 $y = 1$。

向量计算与 $L_2\text{ 距离}$：

距离计算公式逻辑即 $PQ = \sqrt{|PA|^2 + |QA|^2}$（勾股定理）。衔接到 Softmax 矩阵的整体逻辑链条：

$$\text{向量 (Vectors)} \xrightarrow{\text{两两 } L_2 \text{ 距离}} \text{距离矩阵 (Distance Matrix)} \xrightarrow{\text{相似度转换}} \text{Logits} \xrightarrow{\text{Softmax}} \text{概率矩阵 (Probability Matrix)}$$

对于 $N$ 个 $D$ 维样本构成的矩阵 $X \in \mathbb{R}^{N \times D}$：

$$X = \begin{bmatrix} x_1 \\ x_2 \\ \vdots \\ x_N \end{bmatrix}$$

任意两个向量 $x_i$ 与 $x_j$ 之间的 $L_2$ 欧式距离计算如下：

$$d_{ij} = \|x_i - x_j\|_2 = \sqrt{\sum_{k=1}^D (x_{ik} - x_{jk})^2}$$

遍历所有样本点可得 $N \times N$ 的距离矩阵 $D$：

$$D = \begin{bmatrix} 0 & d_{12} & \dots & d_{1N} \\ d_{21} & 0 & \dots & d_{2N} \\ \vdots & \vdots & \ddots & \vdots \\ d_{N1} & d_{N2} & \dots & 0 \end{bmatrix}$$

对于 $n$ 维向量 $\mathbf{x} = [x_1, x_2, \dots, x_n]^\top$，其 $p$-范数定义为：

$$\|\mathbf{x}\|_p = \left( |x_1|^p + |x_2|^p + \dots + |x_n|^p \right)^{\frac{1}{p}} \quad (p > 0)$$

三种关键范数特性：

  • $p = 0$（$L_0$ 伪范数）：非零元素个数。用于衡量稀疏性（Sparsity），常用于特征选择。
  • $p = 1$（$L_1$ 范数 / 曼哈顿距离）：元素绝对值之和（$\sum |x_i|$）。用于 $L_1$ 正则化 (Lasso)，鼓励参数稀疏化。
  • $p = 2$（$L_2$ 范数 / 欧几里得距离）：物理空间向量长度（$\sqrt{\sum x_i^2}$）。用于 Weight Decay 和 MSE 损失函数，降低过拟合风险。

范数的三个基本条件：

  • 非负性与正定性：\|\mathbf{x}\|_p \ge 0，且 \|\mathbf{x}\|_p = 0 \iff \mathbf{x} = \mathbf{0}。
  • 绝对齐次性：\|\alpha\mathbf{x}\|_p = |\alpha| \cdot \|\mathbf{x}\|_p。
  • 三角不等式：\|\mathbf{x} + \mathbf{y}\|_p \le \|\mathbf{x}\|_p + \|\mathbf{y}\|_p。
import torch

X = torch.tensor([
    [1.0, 1.0, 7.0, 150.0],
    [1.0, 1.0, 10.0, 190.0],
    [0.0, 1.0, 9.0, 130.0]
])

W = torch.tensor([
    [0.2, 0.1, 0.9, 0.3],
    [0.5, 0.2, 0.4, 0.1],
    [0.1, 0.6, 0.8, 0.2]
])

logits = X @ W.T
probabilities = torch.softmax(logits, dim=1)

print(probabilities)

PyTorch 计算解析：

  • 数据维度：$X \in \mathbb{R}^{3 \times 4}$，权重 $W \in \mathbb{R}^{3 \times 4}$。
  • Logits 矩阵：通过矩阵乘法 $Z = X W^\top$（写为 logits = X @ W.T）并行算出行得分。
  • Softmax 归一化：指定 dim=1，在行维度做归一化，转换为概率分布。

关于 PyTorch 的 dim 维度规则：

  • dim=0（竖向/按列）：沿着行的方向滑动，每一列和为 1。
  • dim=1（横向/按行）：沿着列的方向滑动，每一行和为 1（满足分类概率之和为 1 的定义）。

对于输入得分向量 $z = [2.0, 1.0, 3.0]$：

1. Softmin

公式：$p_i = \frac{e^{-x_i/T}}{\sum_j e^{-x_j/T}}$。指数项加入负号，得分越小（距离越近）概率越高。输入转化为 $[-2.0, -1.0, -3.0]$ 后，最小值 $1.0$ 得到最大概率（$66.52\%$）。

2. Hardmax

“胜者通吃”机制。直接将最大值位置置 1，其余置 0（如输出 $[0, 0, 1]$）。由于存在离散突变，不可导，无法通过梯度下降更新。若温度 $T \to 0$，Softmax 会直接退化为 Hardmax。

3. 温度系数（Temperature $T$）

通过 $e^{x_i/T}$ 控制分布平滑度：

  • 低温度 ($T = 0.5$)：放大得分差距，最大项占绝对主导（输出尖锐/自信）。
  • 高温度 ($T = 5.0$)：缩小得分差距，各类概率趋于均匀（增加随机性与多样性）。

import torch

X = torch.tensor([
    [1.0, 1.0, 7.0, 150.0],
    [1.0, 1.0, 10.0, 190.0],
    [0.0, 1.0, 9.0, 130.0]
])

W1 = torch.tensor([
    [0.2, 0.1, 0.9, 0.3],
    [0.5, 0.2, 0.4, 0.1],
    [0.1, 0.8, 0.6, 0.2]
])

H = X @ W1.T
print("H:\n", H)

W2 = torch.tensor([
    [0.2, 0.4, 0.3],
    [0.5, 0.1, 0.2]
])

Y = H @ W2.T
print("Y:\n", Y)

W_eff = W2 @ W1
print("W_eff:\n", W_eff)

Y_eff = X @ W_eff.T
print("Y_eff:\n", Y_eff)

prob = torch.softmax(Y, dim=1)
print("Softmax(Y):\n", prob)

前向传播矩阵推导与折叠现象拆解：

  1. 隐藏层计算：$H = X (W^{(1)})^\top \in \mathbb{R}^{3 \times 3}$。
  2. 输出层计算：$Y = H (W^{(2)})^\top \in \mathbb{R}^{3 \times 2}$。
  3. 矩阵合并推导： $$Y = X(W^{(1)})^\top (W^{(2)})^\top = X (W^{(2)}W^{(1)})^\top \implies W_{\text{effective}} = W^{(2)}W^{(1)}$$

核心结论：缺少非线性激活函数时，无论叠加多少层网络，均可折叠为等价的单层线性网络。

微观视角与宏观视角等价性：

  • 微观视角：单神经元计算 $\bar{h}_1 = x W_1 + b_1 \xrightarrow{\sigma} h_1 = \sigma(\bar{h}_1)$。
  • 宏观视角：全层矩阵并行运算 $\bar{h} = xW + b \xrightarrow{\sigma} h = \sigma(\bar{h})$，利用 GPU 完成高并发加速。

XOR 线性不可分问题：

XOR（异或）真值表如下，无法通过二维空间中的一条直线划分类别：

输入 $x_1$ 输入 $x_2$ 输出 $y = x_1 \oplus x_2$ 类别归属

步骤 / 指标 无激活函数 (Without Activation) 有 ReLU 激活函数 (With ReLU)

Logits 计算 正负数直接抵消，结果全为 $[0.00, 0.00]$ 消除抵消，得到高对比度得分 $[2.00, 0.00]$

核心原理解析

1. 无激活函数崩溃原因： 未经过非线性截断时，$Z_1$ 的正负数值在第二层直接抵消，神经网络无法提取有效的空间特征，模型退化。

2. ReLU 的关键作用： $\text{ReLU}(z) = \max(0, z)$ 强制截断负数，打破了线性的对称抵消，成功扭曲特征空间并解决非线性分类问题。

激活函数 数学公式 $\sigma(z)$ 输出范围 导数公式 $\sigma'(z)$ 核心特性与局限
Sigmoid $\frac{1}{1 + e^{-z}}$ $(0, 1)$ $\sigma(z)(1 - \sigma(z))$ 处处连续可导，但两侧极易引发梯度消失（导数最大值 0.25）；非零中心化导致收敛慢。
Tanh $\frac{e^z - e^{-z}}{e^z + e^{-z}}$ $(-1, 1)$ $1 - \sigma^2(z)$ 零中心化，收敛速度快于 Sigmoid；但两侧饱和区依然存在梯度消失问题。
ReLU $\max(0, z)$ $[0, +\infty)$ $$\begin{cases} 1 & z \ge 0 \\ 0 & z < 0 \end{cases}$$ 计算极快（无指数运算），正半轴无上限可缓解梯度消失；缺点是负半轴有神经元坏死风险。

深度思考：代码中写了激活函数，模型就一定获得了非线性能力吗？

结论：不一定。

若输入数据与权重均大于 0，使得所有节点都落在线性区间（$z > 0$），$\text{ReLU}(z)$ 会退化为纯线性映射 $f(x) = x$。激活函数只有在数据能够触及非线性截断区（$z \le 0$）时，才能真正为网络引入非线性变换能力。
