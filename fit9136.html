FIT9136 Introduction to Python

  • 本课程会系统介绍 Python 编程语言的核心概念与应用，包括数据类型、控制结构、函数、模块以及面向对象编程。
  • 课程通过项目和练习帮助学生提升编程能力，并训练用代码解决实际问题的思维方式。

主要内容

  • Python 基础语法
  • 递归
  • 面向对象编程、正则表达式与 unittest

作业攻略

先来讲讲 Assignment 1 是个怎么样的形式：首先会有三个小 subtask 需要你做，但是这三个小的 subtask 不计入成绩当中去，最重要的还是以最后的 task 为主。这导致有些人可能想说我能否直接跳过前面三个 subtask，直接去做最后的 task 呢？答案是不能的，因为最后的 task 是需要调用前面三个 subtask 的函数的，所以你必须把前面三个 subtask 都做完才能去做最后的 task。也就是说前面的 subtask 是和后面的相关联的。

总结下 Assignment 1 的核心是把 Python 基础语法写稳。这一阶段不要急着追求复杂写法，重点是把 input()、print()、变量、类型转换、四则运算、取整除、取余、if/elif/else、字符串切分、列表循环、字典和函数签名写准确。题目通常会给很明确的输入输出格式，最重要的是逐字对齐 expected output，并且函数题不要在函数内部乱用 input() 或 print()。

举个例子吧：现在有个摩托的价格需要算出来，题目如下：

Welcome to the motor line item test script.

Motor price: $22.99

How many motors would you like to buy: 10
Total price: $229.90

那么 numerically 就需要把这个题目拆成几个小步骤：

  1. 先把第一句话进行 print 输出，打印出来就是 Welcome to the motor line item test script.
  2. 再把第二句话进行 print 输出，打印出来就是 Motor price: $22.99
  3. 然后你需要获取用户输入的数量，使用 input() 函数来获取用户输入的数量，如果最后输出的是 float 就得 input 给转换成 float。
  4. 最后算出总价 22.99 * 10

subtask 1.2 同理 例子为：

Product Name Price
motor $22.99
sensor $65.75
frame $70.10
cpu $95.50

进行拆分：

  1. 先定义数据，比如 products = ['motor', 'sensor', 'frame', 'cpu']，以及 prices = [22.99, 65.75, 70.10, 95.50]。
  2. 通过 print() 函数打印 '-' 和字符串 "products name | price"，最后再打印一段 '-'，搭建好基础框架。
  3. 遍历 products 和 prices 列表：使用 len(products) 获取列表长度（4），用 range(4) 生成序列 0, 1, 2, 3，利用 for i in ... 让循环变量 i 作为索引访问列表元素。
  4. 根据当前索引 i，分别从 products 和 prices 中取出值，赋值给 current_products 和 current_prices。
  5. 使用 f-string 进行格式化输出：print(f"{current_products:<12} | ${current_prices:.2f}")。
    • {current_products:<12}：产品名称靠左对齐，固定占 12 个字符宽度（不够补空格），确保竖线对齐。
    • |：原样输出竖线分隔符。
    • $：原样输出美元符号。
    • {current_prices:.2f}：价格保留 2 位小数输出（如 120.00）。

subtask 1.3

主要考察的是 if，else 和 elif。

题目为：Your boss wants you to undertake one last exploration... A conditional discount calculator. You are to write a simple program that prompts the user for the end sales price and applies a conditional discount. The discounts are as follows: 30% for orders over $500.00, 15% for orders over $200.00, and 5% for orders over $50.00.

Welcome to the discount calculator.

Enter sales amount(dollars): 10.00 or 51.00 or 201.00 or 501.00
Discounted price: $10.00 or $48.45 or $170.85 or $350.70

解析：

  1. 先打印欢迎语句 Welcome to the discount calculator.
  2. 获取用户输入的销售金额，使用 input() 函数获取用户输入的销售金额，并将其转换为浮点数。
  3. 根据输入的销售金额应用条件折扣：
    • 如果销售金额大于 500.00，应用 30% 的折扣。
    • 如果销售金额大于 200.00，应用 15% 的折扣。
    • 如果销售金额大于 50.00，应用 5% 的折扣。
    • 否则，不应用任何折扣。

最后的大作业: TASK 1 Quote Calculator (Assessed)

这里的作业要求你怎么通过 code 计算提供的材料，然后所有的 coding 逻辑都是基于之前所学的。

题目为：Your boss now wants you to take what you have learned and create a functional quote calculator for the Smart Maker Components division. Your boss would like you to formalise what you did in subtask 1.2 by creating two aligned lists product_name, containing a list of product names, and product_price, containing a list of product prices. You should populate this list using the table below.

解析：

  1. 首先准备数据结构，比如创建两个位置对应列表 product_name 和 product_price。
  2. 打印欢迎语句 Welcome to the Smart Maker Quote Calculator. 还有 For each product below, please specify your required quantity.；接着创建一个空列表专门用来存放数量，再通过循环遍历所有产品名称，使用 input() 动态获取输入。关键点：使用 int() 转成整数后通过 .append() 追加到列表中。
  3. 遍历用户输入的数量，计算每个产品的总价。初始化 subtotal = 0.0 累加总价，使用 for i in range(len(product_name)): 提取名称、单价和数量，计算单项总价后通过 subtotal += line_total 进行累加。
  4. 根据阶梯规则计算折扣。使用 if-elif-else 结构实现条件判断，按从大到小的顺序（>1500 -> >1000 -> >300）进行梯级判定，避免条件覆盖。
  5. 打印报价单。输出详细报价，包括数量、单价、单项总价以及最终的小计、折扣和折后总价，统一使用 f-string 格式化为保留 2 位小数。

学习建议

  • 先把基础概念学扎实，明确每一段代码在做什么、为什么这样写。
  • 多做编程练习，尤其是手写代码训练，这对提升编码能力和逻辑思维非常重要。
  • 可以参考下面的 FIT9136 专门学习站点，先学会如何为小函数设计 test case，再根据测试结果一步步手搓代码。这样比直接看答案更能训练真实的 debug 和现场 coding 能力。

常见难点

  • 面向对象编程、正则表达式和小组作业通常是最容易卡住的部分。
  • 小组作业的难度会大幅提升，尤其是 interview 部分。建议提前准备，确保自己能清楚解释代码逻辑。
  • 考试主要考察现场写代码的能力，建议在接近考试的阶段多做限时练习，尽量模拟真实考试环境。
